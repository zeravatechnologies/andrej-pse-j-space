# PSE-A: PSE Analyzer

Spectral anatomy and J-space of local GGUF models. The working repository of PSE-A; released builds of PSE Analyzer are published from [zeravatechnologies/pse-analyzer](https://github.com/zeravatechnologies/pse-analyzer).

- **Download:** <https://www.zeravatech.ca/products/pse-analyzer/>, for Ubuntu and Windows, with SHA-256 checksums

The code is in [`pse_a/`](pse_a/); the design documents (`PSE-A_*.docx`) are beside it.
